# Kunim — shaxsiy reja va moliya

O‘zbekcha va ruscha interfeysli, mobil hamda kompyuterga mos shaxsiy reja va moliya prototipi.

## Ishga tushirish

Node.js 20 yoki yangirog‘ini o‘rnating, repository'ni clone qiling va loyiha papkasida:

```bash
npm install
npm run dev
```

Terminal ko‘rsatgan mahalliy manzilni brauzerda oching (odatda `http://localhost:5173`). Ishlab chiqarish buildini tekshirish uchun `npm run build` buyrug‘ini bajaring.

## Hozirgi imkoniyatlar

- O‘zbekcha va ruscha interfeysni almashtirish
- Kunlik vazifalarni sana/vaqt bilan qo‘shish va bajarilgan deb belgilash
- So‘mda kirim va chiqimlarni kategoriya bilan qayd qilish
- Oy сон bo‘yicha шaxsiy moliya jamlanmasi va toifalar bo‘yicha хulosa
- Maqsad qo‘shish va bajarilish foizini ko‘rish
- Mobil navigatsiya va moslashuvchan desktop ko‘rinish

## Muhim cheklovlar

Bu hozircha frontend prototipi. Ma’lumotlar brauzerning `localStorage` xotirasida saqlanadi; akkaunt, sinxronlash, server bazasi, Google/telefon orqali autentifikatsiya va haqiqiy AI hisoboti ulanmagan. Shu sababli maxfiy yoki muhim moliyaviy ma’lumotlarni kiritmang. Haqiqiy foydalanuvchilar uchun backend va autentifikatsiya qo‘shish kerak.
